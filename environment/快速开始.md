# 新电脑安装环境：五步操作

适用：Windows x64 电脑。首次恢复 Python 环境需要联网。现在要转移到另一台电脑，直接复制完整项目即可。

## 先看顺序

```mermaid
flowchart LR
    A["① 复制完整项目"] --> B["② 安装 Miniconda"]
    B --> C["③ 双击安装入口"]
    C --> D["④ 按用途启动软件"]
    D --> E["⑤ 确认可以使用"]
```

## 照着操作

| 顺序 | 你要做什么 | 怎么知道成功了 |
|---|---|---|
| ① 准备项目 | 将完整的 `Semantic-Data-Technologies` 文件夹复制到新电脑，放在自己方便的位置。 | 文件夹中有 `environment`、`plugins`、`assignments` 三个目录。 |
| ② 安装 Miniconda | 打开 [Miniconda 官方安装说明](https://www.anaconda.com/docs/getting-started/miniconda/install)，选择 Windows x64 安装版，建议使用默认安装位置。已有 Miniconda 可跳过。 | 开始菜单能找到并打开 **Miniconda Prompt**。 |
| ③ 一键恢复环境 | 进入项目的 `environment` 文件夹，双击 **`install-environment.bat`**，保持联网，等待安装完成。 | 窗口出现 **“环境检查及安装完成。”** |
| ④ 启动需要的软件 | 按下面的“启动文件对照表”双击相应文件，不需要每次重新安装。 | 对应的软件窗口或网页能正常打开。 |
| ⑤ 做一次确认 | 在 Jupyter 中选择 **Python (ARU)** 新建笔记本，运行下方两行代码；需要使用本体时，再用 Protégé 打开作业 OWL。 | Python 路径包含 `envs\ARU`；Protégé 能打开作业文件。 |

安装入口会准备 Java、Fuseki、Protégé、中文插件，以及 ARU 的 Python/Jupyter 依赖。已有同名 Python 环境会保留；版本不一致时会提示错误，不会自动删除。

## 启动文件对照表

这三个文件都在 `environment` 文件夹中，按用途选择。

| 你想做什么 | 双击哪个文件 | 打开后怎么用 |
|---|---|---|
| 编辑本体、运行推理 | `start-protege.bat` | 打开 `assignments/Hopfield_Sports_Ontology/Hopfield_Sports_Ontology.owl`。首次切换中文：帮助菜单（Help）→ 简体中文界面。 |
| 启动知识库服务 | `start-fuseki.bat` | 看到 **`Start Fuseki`** 后，浏览器打开 <http://127.0.0.1:3030/>。**保留运行窗口，关闭窗口或按 Ctrl+C 都会停止服务。** |
| 写 Python、使用笔记本 | `start-jupyterlab.bat` | 浏览器自动打开中文 JupyterLab，选择 **Python (ARU)** 内核。 |

笔记本验证代码：

```python
import sys
print(sys.executable)
```

输出类似 `D:\miniconda3\envs\ARU\python.exe` 即可，具体盘符可以不同。

## 遇到问题先看这里

| 现象 | 怎么处理 |
|---|---|
| 提示找不到 Miniconda | 确认已安装；如果使用自定义安装位置，从开始菜单打开 Miniconda Prompt，进入项目的 `environment` 目录，再运行 `install-environment.bat`。 |
| 安装提示错误、没有出现完成提示 | 保留窗口，查看第一处错误；不要反复删除已有 ARU 环境。 |
| Fuseki 网页打不开 | 检查运行窗口是否仍在、是否出现 `Start Fuseki`；若提示端口占用，先正常关闭另一份 Fuseki。 |

## 迁移时记住三件事

1. **复制完整项目**，不要只拿走 `environment`，也不要直接复制旧电脑的 `miniconda3/envs/ARU` 代替安装。
2. 使用 Git 迁移时，先确认 `environment` 和插件文件已提交并同步；仅在本机新建的文件不会自动出现在另一台电脑。Git 不包含大软件包和活动数据库，安装脚本会下载软件；要携带数据库，先停服再复制 `environment/data/fuseki`。
3. 当前包含 Python 与语义数据技术基础环境；**PyTorch、TensorFlow 和 GPU 环境尚未配置**，以后按课程需要安装。尚未在另一台实体电脑上验证。

更详细的版本、目录与迁移说明见 [环境说明](README.md)。
