02

Understand the model

A class describes a kind of thing; an individual is a particular thing; a property connects entities or gives a literal value. The diagrams below show selected parts of the submitted model.

Class → individual

  • Athlete → LionelMessi
  • NationalTeam → ArgentinaNationalTeam
  • FootballSport → Football
  • FootballSport is a class; Football is an individual used as the value of playsSport. They use different IRIs.

Object vs datatype property

  • LionelMessi → memberOf → ArgentinaNationalTeam
  • LionelMessi → athleteAge → 37
  • The first object is another entity. The second is an integer literal, with its age snapshot fixed at 2024-07-01.

Why membership is a record

A direct memberOf link cannot say when or for which tournament a player belonged to a team. A TeamMembership record links the athlete, team, competition and dates together.

The direct memberOf / hasAthlete links are historical shortcuts. They do not establish a current roster or contemporaneous teammates. QA14 joins two time-overlapping membership records instead.

CoachingAssignment similarly records a coach, team and dates. AthleteParticipation records the team an athlete represents in a competition. CompetitionSeries distinguishes a recurring tournament from a particular CompetitionEdition.

Operate in Protégé

  1. Open the English submission
    Start Protégé 5.6.9 by running Protege.exe from your installation directory. Use File → Open… and select Hopfield_Sports_Ontology.owl. Confirm the active ontology is Hopfield Sports Ontology.
  2. Inspect the overview
    On Active ontology, check the ontology IRI, creator Hopfield and metrics. Protégé may show 47 classes because it includes owl:Thing; the file has 46 named domain classes.
  3. Navigate entities
    Open Entities. Use Classes, Object properties, Data properties and Individuals. Expand a node with its triangle. Select an entity to see its annotations and axioms on the right.
  4. Start HermiT
    Choose Reasoner → HermiT, then Reasoner → Start reasoner. Wait until classification finishes. A HermiT active status confirms the reasoner is running; use the supplied validation JSON for the explicit consistency checks.
  5. Open the SPARQL view
    Select the SPARQL Query tab. If absent, enable it through Window → Tabs → SPARQL Query. The local installation includes RDF Library and its compatibility fragment.
  6. Paste and execute
    Open a query file in a text editor, copy all text including PREFIX, click inside the query editor, select all, paste, then click Execute. Copying the query from this guide is equivalent. A .rq file is query text, not an ontology to open with File → Open.
  7. Read the output and repeat
    Read variable names across the result header, compare values and row count with results/, and explain why they follow from the graph. Run each of the five examples in turn. Changing a query changes what is asked, not the stored ontology.
HermiT and SPARQL serve different purposes. HermiT checks logical consequences and consistency; a query retrieves matching graph patterns. Starting HermiT does not automatically mean every SPARQL plugin includes every inferred triple. The supplied queries were checked against the saved RDF graph.

Five query demonstrations

For each demonstration: state the question, identify the entities and properties, run the query, read the result, and explain the modelling decision. The tables below reproduce the checked outputs; they are not live queries.

Q02COUNT DISTINCT aggregation over competition-scoped membership records

How many athletes are in Argentina's 2022 FIFA World Cup squad?

  • Open queries/Q02.rq and run it against the submitted ontology. Keep the Argentina team and FIFAWorldCup2022 IRIs unchanged for this demonstration.
  • Follow TeamMembership to membershipTeam, membershipCompetition and memberAthlete. Read athleteCount from the one-row result.
  • Explain that 26 is the final competition roster count, not the number who played in a particular match.

Why this query works: DISTINCT counts each athlete once. The competition filter separates the 2022 national-team squad from club memberships and other time periods.

queries/Q02.rq
PREFIX sports: <http://www.example.org/sports-ontology#>

# Question: How many athletes are in Argentina's 2022 FIFA World Cup squad?
# Count competition-specific membership records, rather than mixing club and national-team memberships from different periods.
SELECT (COUNT(DISTINCT ?athlete) AS ?athleteCount)
WHERE {
  ?membership a sports:TeamMembership ;
              sports:membershipTeam sports:ArgentinaNationalTeam ;
              sports:membershipCompetition sports:FIFAWorldCup2022 ;
              sports:memberAthlete ?athlete .
}

Expected output

One result row: athleteCount = 26.

athleteCount
26

queries/Q02.rq · results/Q02.csv

Why not count hasAthlete directly?

hasAthlete is a historical shortcut. Competition-scoped TeamMembership records make the roster being counted explicit.

Does 26 mean that every player appeared in the final?

No. Roster membership is distinct from playedInMatch. The dataset only records selected actual match appearances.

The Argentina final roster is complete within this stated scope. Other World Cup rosters are selected records.

Q06Multi-property join with OPTIONAL penalty-shoot-out fields

What were the scores of both teams in the 2022 FIFA World Cup final?

  • Open queries/Q06.rq. Start from FIFAWorldCup2022 finalMatch and inspect the home and away team columns together with their scores.
  • Read the normal match score as 3:3 after extra time. Read penaltyHomeScore and penaltyAwayScore separately as 4 and 2.
  • Point to OPTIONAL: a match without a shoot-out can still remain in the result with unbound penalty columns.

Why this query works: A single score literal cannot identify the team or distinguish match goals from shoot-out penalties. Separate fields preserve the meaning and allow numeric filtering.

queries/Q06.rq
PREFIX sports: <http://www.example.org/sports-ontology#>

# Question: What were the scores of both teams in the 2022 FIFA World Cup final?
# Home and away scores include extra time. Penalty-shootout scores are displayed separately and are not added to match goals.
SELECT ?match ?homeTeam ?homeScore ?awayTeam ?awayScore ?penaltyHomeScore ?penaltyAwayScore
WHERE {
  sports:FIFAWorldCup2022 sports:finalMatch ?match .
  ?match sports:homeTeam ?homeTeam ;
         sports:awayTeam ?awayTeam ;
         sports:homeScore ?homeScore ;
         sports:awayScore ?awayScore .
  OPTIONAL { ?match sports:penaltyHomeScore ?penaltyHomeScore . }
  OPTIONAL { ?match sports:penaltyAwayScore ?penaltyAwayScore . }
}

Expected output

Argentina 3:3 France after extra time; Argentina won the penalty shoot-out 4:2. The query returns one match row.

matchhomeTeamhomeScoreawayTeamawayScorepenaltyHomeScorepenaltyAwayScore
WorldCupFinal2022ArgentinaNationalTeam3FranceNationalTeam342

queries/Q06.rq · results/Q06.csv

Why are the penalty fields OPTIONAL?

Not every match has a penalty shoot-out. Requiring penalty fields would wrongly remove matches without those fields.

Should the final score be shown as 7:5?

No. Shoot-out penalties are not added to the 3:3 match score. The two results represent different scoring stages.

homeTeam and awayTeam are nominal fixture sides; they do not imply that the neutral final had a home-ground advantage.

Q16Conditional BIND IF expression plus numeric FILTER and joins

Which football competitions include a match in which the winning team scored more than three goals?

  • Open queries/Q16.rq and identify hasWinner, homeTeam, awayTeam, homeScore and awayScore.
  • Explain FILTER (?winner IN (?homeTeam, ?awayTeam)), then BIND IF: choose the home score when the winner is home; otherwise choose the away score.
  • Run the query. Read FIFAWorldCup2022, EnglandIran2022, EnglandNationalTeam and goals = 6.

Why this query works: The threshold applies to the winning team, not to a fixed home side, and shoot-out penalties are excluded. The membership test ensures that the winner is one of the two fixture sides.

queries/Q16.rq
PREFIX sports: <http://www.example.org/sports-ontology#>

# Question: Which football competitions include a match in which the winning team scored more than three goals?
# Use the winning team's home or away score. Penalty-shootout goals are excluded.
SELECT DISTINCT ?competition ?match ?winner ?goals
WHERE {
  ?competition sports:competitionSport sports:Football .
  ?match sports:inCompetition ?competition ;
         sports:hasWinner ?winner ;
         sports:homeTeam ?homeTeam ;
         sports:awayTeam ?awayTeam ;
         sports:homeScore ?homeScore ;
         sports:awayScore ?awayScore .
  FILTER (?winner IN (?homeTeam, ?awayTeam))
  BIND (IF(?winner = ?homeTeam, ?homeScore, ?awayScore) AS ?goals)
  FILTER (?goals > 3)
}
ORDER BY ?competition ?match

Expected output

One match qualifies in the recorded data: England defeated Iran 6:2 in FIFAWorldCup2022; the winning team scored 6 goals.

competitionmatchwinnergoals
FIFAWorldCup2022EnglandIran2022EnglandNationalTeam6

queries/Q16.rq · results/Q16.csv

Why not filter homeScore > 3?

The winning team could be the away side. BIND IF makes the threshold follow the winner.

Does the World Cup final qualify because Argentina scored four penalties?

No. Its match score is 3:3; shoot-out penalties are stored separately and excluded from goals.

The result lists qualifying matches only from the selected matches entered in this ontology; it is not a complete historical search.

Q21Class path, numeric and date filters, OPTIONAL end date, BOUND and ORDER BY

Which athletes were under 25 and playing for a basketball team on 1 July 2024?

  • Open queries/Q21.rq. Explain the age snapshot date of 2024-07-01 and the TeamMembership interval.
  • Check the start date is on or before the reference date and the end date is absent or on or after it.
  • Run the query and read the result in ascending age order: Victor Wembanyama, 20, San Antonio Spurs; Anthony Edwards, 22, Minnesota Timberwolves.

Why this query works: A stored age and a team membership are time-dependent. Aligning their reference date avoids combining a historical team with an unrelated current age. OPTIONAL and BOUND allow a recorded open-ended interval.

queries/Q21.rq
PREFIX sports: <http://www.example.org/sports-ontology#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

# Question: Which athletes were under 25 and playing for a basketball team?
# Use 1 July 2024 as the common reference date for both the stored age snapshot and the membership interval.
SELECT DISTINCT ?athlete ?age ?team
WHERE {
  ?athlete a/rdfs:subClassOf* sports:Athlete ;
           sports:athleteAge ?age .
  ?membership a sports:TeamMembership ;
              sports:memberAthlete ?athlete ;
              sports:membershipTeam ?team ;
              sports:validFrom ?from .
  OPTIONAL { ?membership sports:validTo ?to . }
  ?team sports:playsSport sports:Basketball .
  FILTER (?age < 25)
  FILTER (?from <= "2024-07-01T00:00:00"^^xsd:dateTime)
  FILTER (!BOUND(?to) || ?to >= "2024-07-01T00:00:00"^^xsd:dateTime)
}
ORDER BY ?age ?athlete ?team

Expected output

Two rows: VictorWembanyama, 20, SanAntonioSpurs; AnthonyEdwards, 22, MinnesotaTimberwolves.

athleteageteam
VictorWembanyama20SanAntonioSpurs
AnthonyEdwards22MinnesotaTimberwolves

queries/Q21.rq · results/Q21.csv

Are these their ages today?

No. athleteAge is calculated on 2024-07-01 and ageAsOf records that snapshot date. A new reference date requires recalculating ages and checking membership intervals.

What does a missing validTo mean in this query?

The query treats it as an open-ended recorded interval. Under the open-world assumption it is not proof that membership continues forever.

This is a selected basketball sample, not every under-25 basketball player worldwide.

Q22MAX aggregate subquery joined back to return all ties

Which team has won the most men's FIFA World Cup titles through 2022?

  • Open queries/Q22.rq and identify the inner SELECT (MAX(?count) AS ?maxTitles).
  • Explain why the outer pattern retrieves teams whose fifaWorldCupTitles equals the maximum instead of using LIMIT 1.
  • Run the query. Read BrazilNationalTeam and titles = 5, using the dataset cutoff through the 2022 tournament.

Why this query works: fifaWorldCupTitles keeps a single tournament-series scope, avoiding comparisons between World Cup, NBA and club trophies. Joining back to MAX correctly returns every tied team.

queries/Q22.rq
PREFIX sports: <http://www.example.org/sports-ontology#>

# Question: Which team has won the most men's FIFA World Cup titles?
# Compare titles from this tournament series only, rather than total trophies from unrelated competitions.
# Return every team tied for the highest title count.
SELECT DISTINCT ?team ?titles
WHERE {
  { SELECT (MAX(?count) AS ?maxTitles)
    WHERE { ?candidate sports:fifaWorldCupTitles ?count . }
  }
  ?team sports:fifaWorldCupTitles ?titles .
  FILTER (?titles = ?maxTitles)
}
ORDER BY ?team

Expected output

One row: BrazilNationalTeam, 5 titles. The recorded title-count cutoff is the 2022 World Cup.

teamtitles
BrazilNationalTeam5

queries/Q22.rq · results/Q22.csv

Why not ORDER BY DESC(?titles) LIMIT 1?

That would discard tied winners. The MAX subquery preserves every team at the maximum count.

Why not use a generic trophyCount?

Trophies from different competitions are not comparable without a shared scope. This property specifically counts men's FIFA World Cup titles.

The cutoff is explicit. Future tournament results are outside the recorded total until the data is updated.

06

Explain & defend

Practise saying the short answer in your own words, then point to the relevant entity, axiom or query. These are preparation notes: make sure you understand each claim before using it in assessment.

What is the open-world assumption?

A missing assertion is unknown, not automatically false. An empty query result only means no matching recorded data was found.

Are domain and range validation rules?

In OWL they imply types: using a property can infer the subject domain and object range. They do not reject an undeclared object like a database foreign-key constraint.

Why model TeamMembership as a separate class?

A direct athlete-to-team link has no place for dates or a competition roster. TeamMembership relates an athlete, a team, an interval and optionally a competition.

Why is hasWinner not required for every match?

A match may be drawn, cancelled or unfinished. The production data records winners for selected completed team matches, but the model does not impose a universal winner requirement.

Why are shoot-out penalties separate from homeScore and awayScore?

homeScore and awayScore describe normal and extra-time goals. penaltyHomeScore and penaltyAwayScore describe the shoot-out. Combining them would distort goal-based filters.

What is the difference between asserted and inferred facts?

Asserted facts are explicitly stored. Inferred facts follow from axioms, such as inverse properties or equivalent classes. Some inverse and parent-type facts are also stored explicitly so queries work without a reasoner.

Can OWL detect that an athlete refers to a missing team?

Not reliably under the open-world assumption. QA13 checks the raw asserted graph with FILTER NOT EXISTS for a declared team or team subclass. Range inference could otherwise turn an undeclared reference into a team.

Does an empty QA15 prove that every fact is correct?

No. QA15 performs selected checks for explicit disjoint types, negative scores and unequal values of functional data properties. HermiT checks logical consistency separately; neither verifies every real-world sports fact.

How are classes and sport individuals separated?

FootballSport is a class; Football is an individual of FootballSport and Sport. They have different IRIs, avoiding the same-name class/individual punning used in the starter.

How large is the ontology?

It has 46 named classes, 45 object properties, 18 datatype properties and 222 named individuals. Protégé may display 47 classes because its metrics include owl:Thing.

Which data scopes are complete and which are selected?

The final Argentina 2022 World Cup roster has 26 players and Paris 2024 men's football has 16 teams within the stated scope. Other rosters, appearances, leagues, venues and matches are selected teaching records.

Can two people be inferred to be teammates merely because they were ever in the same club?

No. QA14 requires the same team and overlapping membership intervals, excludes the athlete himself and returns the recorded overlap evidence.

Can participation in the same competition infer an opponent?

No. They may be teammates or never meet. Q10 requires an asserted opponent relationship and evidence that both athletes played in the same official match.

Why are Athlete and Coach not disjoint?

One person can be both an athlete and a coach, including at different periods. Declaring them disjoint would reject a legitimate multi-role person.

Why use xsd:dateTime for recorded dates?

The dates use xsd:dateTime with midnight times so the ontology passes the installed OWL 2 DL profile check and the SPARQL comparisons use matching datatypes.

What do the HermiT checks establish?

The submitted ontology is consistent, has no unsatisfiable named classes and passes OWL 2 DL. Separate in-memory negative cases correctly fail for Athlete/Venue dual typing, two different homeScore values and negative venue capacity.

What does a functional datatype property mean?

One individual can have at most one data value for that property. Two distinct numeric values such as homeScore 3 and 4 create an inconsistency; a missing value is not automatically an inconsistency.

Why are Olympic football teams separate from senior national teams?

The Paris 2024 men's event uses tournament-specific Olympic-team individuals, avoiding an accidental claim that the senior World Cup squad is the same roster.

Why are Q15, QA13 and QA15 empty?

No entered record supports a coach of both football and basketball; no invalid team reference or selected contradiction was found. These are expected dataset results, not claims about every real-world record.
